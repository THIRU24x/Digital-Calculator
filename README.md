🧮 Digital Calculator

A modern and interactive Digital Calculator built using HTML, CSS, and JavaScript. This project allows users to perform basic arithmetic operations such as addition, subtraction, multiplication, and division through a simple and user-friendly interface.

✨ Features:

➕ Addition
➖ Subtraction
✖️ Multiplication
➗ Division
🧹 Clear and delete functions
🔢 Easy-to-use number buttons
📱 Clean and responsive design

💻 Technologies Used:
HTML • CSS • JavaScript

This project helped me strengthen my understanding of JavaScript functions, DOM manipulation, event handling, user input, and basic programming logic. It is one of my projects while building stronger frontend development and JavaScript skills. 🚀
